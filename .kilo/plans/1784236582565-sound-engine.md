# Milestone 6: Sound Engine — Implementation Plan

## Summary

Add audio (SFX + music) to the game. `AudioManager` lives in `MonoGameLearning.Core` as a reusable service. SFX are triggered via state callback configs (extending existing `PlayerStateControllerConfig` / `EnemyStateEntryCallbacks` patterns). Music switches on game state transitions with hard cuts. Volume and music track settings are persisted to the existing `settings.json`. Placeholder audio assets are generated programmatically as `.wav` files. Volume controls are added to the Settings screen.

---

## Architecture Overview


## Task 2: AudioManager — Core Service

**File:** `MonoGameLearning.Core/Audio/AudioManager.cs`

```csharp
namespace MonoGameLearning.Core.Audio;

public class AudioManager
{
    public float SfxVolume { get => _settings.SfxVolume; set => SetVolume(sfx: value); }
    public float MusicVolume { get => _settings.MusicVolume; set => SetVolume(music: value); }

    // Create in GameCore ctor; audio content loaded via ContentManager later
    public AudioManager();

    // Called from GameLoop.LoadContent — loads all .wav files
    public void LoadContent(ContentManager content);

    // One-shot SFX
    public void PlaySfx(SfxId sfx);

    // Music: play a track (hard cut). Pass null to stop.
    public void PlayMusic(MusicId? track);

    // Called when game pauses/unpauses — reduces music volume during pause
    public void SetPaused(bool paused);

    public void Update(GameTime gameTime); // processes MusicInstance state
}
```

### Implementation Details

**Internal structure:**

- `Dictionary<SfxId, SoundEffectInstance[]>` — pool of pre-created instances per SFX (e.g., 3 instances each to allow overlapping). Round-robin dispatch in `PlaySfx`.
- `MusicInstance?` — currently playing music. When `PlayMusic` is called with a different track, the old `SoundEffectInstance` is stopped and a new one started.
- `SetPaused(paused)` — when `paused`, set the current `MusicInstance.Volume = MusicVolume * 0.3f` (muted). When unpaused, restore to `MusicVolume`.
- All `SoundEffectInstance.Volume` values are cached and recalculated when `SfxVolume` or `MusicVolume` changes.
- `ContentManager` loads all `SoundEffect` assets from `Content/audio/` — the loading code maps `SfxId` and `MusicId` to `SoundEffect` by string-concatenated paths.

**Wiring pattern:**

- `GameCore` constructor creates `AudioManager` property (like `Gum` property)
- `GameLoop.LoadContent` calls `AudioManager.LoadContent(Content)`
- `GameLoop.Update` calls `_audioManager.Update(gameTime)` (before or after gameplay update — handled even when paused since music continues)
- `GameLoop` state machine `OnTransitioned` callback triggers `_audioManager.PlayMusic(...)` based on destination state
- `_gameState.Fire(GameTrigger.PauseToggle)` → `_audioManager.SetPaused(true/false)` as needed

**Music state mapping:**

| GameState             | MusicId                                                            |
|-----------------------|--------------------------------------------------------------------|
| TitleScreen, Settings | `MusicId.TitleMenu`                                                |
| Playing, Paused       | `MusicId.Gameplay` (muted when Paused)                             |
| LevelComplete         | `MusicId.LevelComplete` (one-shot sting — played once, then stops) |
| GameOver              | (no music — silence)                                               |

**Edge case — LevelComplete sting:** Play once, do not loop. When the sting ends (`SoundEffectInstance.State == Stopped`), set `MusicInstance = null`. Do not restart on every frame.

## Task 4: Generated Placeholder Audio

**File:** `MonoGameLearning.Game/Content/audio/generate_audio.sh` (or a small C# console tool — see below)

Generate `.wav` files with distinct audio signatures so the developer can hear what's playing:

| SfxId / MusicId | Sound signature |
| --- | --- |
| `AttackSwing1` | 200ms ascending sine 400→800Hz, quick fade |
| `AttackSwing2` | 250ms ascending sine 300→600Hz, slightly different |
| `AttackSwing3` | 300ms ascending sine 500→1000Hz, power hit |
| `EnemyAttackSwing` | 150ms descending sine 600→200Hz |
| `HitLight` | 50ms square wave burst 200Hz |
| `HitHeavy` | 80ms square wave burst 100Hz + low-end thud |
| `Knockdown` | 200ms low rumble 60→40Hz, slow fade |
| `PlayerHurt` | 100ms noise burst + 300ms descending tone |
| `EnemyHurt` | 100ms higher noise burst + 200ms descending tone |
| `EnemyDeath` | 500ms descending tone 800→100Hz with fade |
| `PlayerDeath` | 1s descending tone 600→50Hz, long fade |
| `MenuNavigate` | 30ms high click 1kHz |
| `MenuConfirm` | 100ms two-tone beep 800Hz→1200Hz |
| `GoPromptBell` | 2.5s of repeated bell: 150ms 1kHz sine + 350ms silence, x5 |
| `Music_TitleMenu` | 4s loop: slow ambient sine chord (C-E-G) at low volume |
| `Music_Gameplay` | 4s loop: faster rhythmic pulse at higher energy |
| `Music_LevelComplete` | 2s ascending major chord swell, non-looping |

**Implementation approach:** Write a small C# console program at `MonoGameLearning.Game/Content/audio/AudioGenerator/Program.cs` that uses `System.IO` (binary `.wav` writing) — no external dependencies. Run it once to generate all `.wav` files into `Content/audio/` directory. Add all generated `.wav` files to `Content.mgcb` as `SoundEffect` items via `Content.mgcb` entries (MonoGame's `SoundEffect` class plays both SFX and music — `Song` requires `MediaPlayer` and has platform-specific format support, so we use `SoundEffect` for everything).

Run the generator **manually** as a one-time step. The `.wav` files are committed to the repo.

### WAV Format (PCM, 44100Hz, 16-bit, mono)

The generator creates valid RIFF/WAV headers + PCM sample data. A quick utility:

```csharp
static void WriteWav(string path, float durationSeconds, Func<float, float> sampleFunc)
{
    int sampleRate = 44100;
    int numSamples = (int)(durationSeconds * sampleRate);
    using var fs = File.Create(path);
    using var bw = new BinaryWriter(fs);
    // RIFF header, fmt chunk, data chunk...
    for (int i = 0; i < numSamples; i++)
    {
        float t = (float)i / sampleRate;
        float sample = Math.Clamp(sampleFunc(t), -1f, 1f);
        bw.Write((short)(sample * short.MaxValue));
    }
}
```

### Constructor / Initialize

### LoadContent

Wire entity callbacks:

- `EnemyEntity` — pass `sfx => Audio.PlaySfx(sfx)` (in `EnemyPool` factory or `LevelDirector`)
- `MenuManager` — pass `sfx => Audio.PlaySfx(sfx)` for menu SFX

### Update

```csharp
// Before gameplay update — AudioManager.Update handles SoundEffectInstance lifecycle
Audio.Update(gameTime);

// After state evaluation:
if (_gameState.State == GameState.Paused && !_audioWasPaused)
    Audio.SetPaused(true);
else if (_gameState.State != GameState.Paused && _audioWasPaused)
    Audio.SetPaused(false);
_audioWasPaused = (_gameState.State == GameState.Paused);

// Go prompt bell (inside the Playing block):
if (_levelDirector.ShowGoPrompt && !_goPromptSoundTriggered)
{
    Audio.PlaySfx(SfxId.GoPromptBell);
    _goPromptSoundTriggered = true;
}
else if (!_levelDirector.ShowGoPrompt)
    _goPromptSoundTriggered = false;
```

### State transitions → Music

```csharp
_gameState.StateMachine.OnTransitioned(t =>
{
    _menuManager.OnGameStateChanged();
    if (t.Destination == GameState.Playing && t.Source != GameState.Paused)
        ResetGame();

    // Music:
    switch (t.Destination)
    {
        case GameState.TitleScreen:
        case GameState.Settings:
            Audio.PlayMusic(MusicId.TitleMenu);
            break;
        case GameState.Playing:
            Audio.PlayMusic(MusicId.Gameplay);
            break;
        case GameState.LevelComplete:
            Audio.PlayMusic(MusicId.LevelComplete); // one-shot sting
            break;
        case GameState.Paused:
            Audio.SetPaused(true);
            break;
        case GameState.GameOver:
            Audio.PlayMusic(null); // stop
            break;
    }
});
```

## Risks & Edge Cases

- **SoundEffectInstance lifecycle**: MonoGame limits concurrent instances (typical limit varies). Pre-pool 3 instances per SFX for overlap support. Round-robin dispatch.
- **LevelComplete sting**: Must not loop. After `SoundEffectInstance.State == Stopped`, set internal `_musicInstance = null`.
- **Settings backward-compat**: If `settings.json` exists from a prior build without audio fields, `AudioSettings` loads with defaults. Do not blow up.
- **No audio files present**: `AudioManager.LoadContent` skips missing files gracefully (try/catch per load, log `Debug.WriteLine`). `PlaySfx` is a no-op if the SFX hasn't been loaded.
- **GC**: `PlaySfx` looks up a pre-allocated `SoundEffectInstance` — zero allocations in hot path. Volume changes create no garbage.
- **Pause mute + volume change while paused**: If the user adjusts `MusicVolume` in settings while paused, the paused-muted volume must reflect the new base volume × 0.3.
